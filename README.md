# 🌟 Gemini AI – Multi-Utility Web Application

A powerful AI application built using Google’s Gemini Pro .
This app offers text chatbot, image captioning, text embeddings, and Q/A features—all in one place.

## 🚀 Features
### 🤖 1. Chatbot (Gemini Pro)

- Real-time text interaction

- Maintains chat history

- Clean conversational UI

### 🖼️ 2. Image Captioning (Gemini-Pro-Vision)

- Upload any image

- Get meaningful captions

- Uses multimodal AI models

### 🔠 3. Text Embeddings

- Generate high-quality embeddings for text

- Useful for semantic search, RAG, clustering

### ❓ 4. Ask Me Anything

- Ask any question

- Gemini model returns precise responses

## 🛠️ Tech Stack

- Python 3.10+

- Streamlit (UI)

- Google Generative AI SDK

- Pillow

- Streamlit Option Menu

## 📁 Project Structure
│── main.py
│── gemini_utility.py
│── config.json
│── requirements.txt

## ⚙️ Installation
- pip install -r requirements.txt
- streamlit run main.py

## 🔑 Setup API Key

Store your Gemini API key in config.json:

{
  "GOOGLE_API_KEY": "your_api_key_here"
}
