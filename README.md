# Gemini-AI-Multi-Utility-Web-Application
Developed a multi-feature AI application integrating Google Generative AI models (Gemini Pro &amp; Gemini Vision) for chatbot interaction, image captioning, embeddings generation, and Q/A tasks. Implemented a modular codebase (gemini_utility.py) and a structured UI using Streamlit. Strong focus on API integration, model usage, and clean UI development.
